# Audit usable capability

Recover the user's requested scope. Use README.md, ROADMAP.md,
docs/reference/supports.md, features.md and direction.md as public authorities.
Inspect relevant source/tests and evidence; repeated summaries are not independent
proof. Preserve newer work when evaluating an older report.

Separate discovery, original-code/model proof, private execution, public API,
installed reuse and natural acceptance. Public synthetic tests and opt-in local
original-byte tests establish different boundaries. A later date or higher test,
signature or RTTI count is not a parity percentage.

Map each claimed workflow to its receiver/ownership/ABI or format dependencies,
public consumer and finish condition. Distinguish shared engine invariants, build
profiles and game semantics; a named game's example is not an engine-wide contract.
Document research blockers and the next discriminating experiment instead of
guessing a completion date or silently narrowing the target.

For publication, inspect the exact tracked tree and reachable history, clean
configure/build/tests, installed files, notices, local links and support wording.
Keep caches, saves/logs, local agent/session procedures and original-byte research
dumps private. Include source/tool limitations and explicit skipped checks. Publish
only within the user's authorization; this skill itself grants none.
